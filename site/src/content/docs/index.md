TypeScript Procedure Factory — a contract-first, end-to-end type-safe RPC library.

**This procedure model, any pipe.** You write a contract, implement it on the server, and call it from a client that never imports server code. Fetch is the default adapter, not the runtime.

Requires Node.js 22+.
