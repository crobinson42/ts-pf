# @ts-pf/http

HTTP wire helpers for ts-pf: `JSONCodec`, `RpcCodec`, `PROTOCOL_HEADER`, URL path join/parse, and `httpStatus`. Analog of [`@ts-pf/message`](../message).

Agent skill: [`skills/ts-pf-http/`](skills/ts-pf-http/). Sync with `npx skills experimental_sync -y`.

Does **not** include `FetchHandler` or `FetchLink`. Those live in [`@ts-pf/server-http`](../server-http) and [`@ts-pf/client-http`](../client-http).

Wire spec: [`packages/protocol/PROTOCOL.md`](../protocol/PROTOCOL.md).
